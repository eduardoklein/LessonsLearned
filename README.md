# Lessons Learned

## Descrição

Projeto desenvolvido para praticar HTML e CSS, criando uma página pessoal com informações sobre aprendizados e objetivos futuros.

## Estrutura de Arquivos

- **index.html**  
  Página principal do projeto, contendo toda a estrutura HTML.

- **style.css**  
  Arquivo de estilos responsável pela aparência da página.

- **images/picture.jpeg**  
  Imagem pessoal utilizada na página.

- **cypress/**  
  Pasta de testes automatizados com Cypress.

- **package.json**  
  Gerenciamento de dependências do projeto.

- **.editorconfig**  
  Configuração de editor para padronização do código.

- **.gitignore**  
  Arquivo para ignorar arquivos e pastas no controle de versão.

## Como executar

1. Clone o repositório
2. Abra o arquivo `index.html` em seu navegador
3. Para rodar os testes, utilize:
   ```sh
   npm install
   npm run test
   ```
